WebDAV

Parcourt récursivement un dossier WebDAV et identifie les films ou séries à partir des noms de fichiers. La lecture reste assurée dans Stremio par un addon dédié comme Davio ↗.

Désactivé par défaut pour les serveurs WebDAV locaux.
À utiliser si le WebDAV devient accessible sans authentification.
Bibliothèques Plex/Jellyfin

Importe directement les films et séries réellement présents dans des bibliothèques ou collections. Plex ↗ · Jellyfin ↗ · lecture Stremio possible avec Plexio ↗ ou Stremio Jellyfin ↗.

Désactivé par défaut pour les serveurs locaux.
API d’indexeurs type Prowlarr, Newznab direct…

Sources Newznab, Prowlarr, Jackett/Torznab et NZBHydra2 paginées.

Projets : Prowlarr ↗ · Jackett ↗ · NZBHydra2 ↗

URL complète de l’endpoint API.
Première collecte jusqu’au plafond, puis reprise incrémentale depuis le curseur mémorisé. La fenêtre de recouvrement absorbe les retards ou réordonnancements de l’indexeur.
Instances WaStream/WaCustom

Indexe les contenus WASource d’une instance WaStream ou WaCustom via leur API administrateur paginée. Les liens de lecture ne sont pas copiés : seuls les identifiants, titres, types et années nécessaires aux catalogues sont importés.

Projets : WaStream ↗ · WaCustom ↗

Le premier parcours est repris sur plusieurs synchronisations lorsque le plafond est atteint. Ensuite, l’API est relue depuis les contenus les plus récents.
Manifestes Stremio

Importe les catalogues déclarés par un autre addon.

Documentation : protocole des addons Stremio ↗. Exemples : YouTubio ↗ · Plexio ↗ · Stremio Jellyfin ↗ · Kitsu Anime ↗ · métadonnées : AIOMetadata ↗.

Synchronisation automatique

Le planificateur vérifie chaque minute les échéances. Il collecte uniquement les sources arrivées à échéance, puis normalise et enrichit le lot, l’injecte dans les catalogues non gelés et invalide leur cache. Stremio lit alors immédiatement le contenu actualisé depuis la même URL d’addon : il n’existe pas de second « envoi » à programmer.
Chaque source peut remplacer cette fréquence depuis la page Sources.

Migration et réparation

Outils avancés pour corriger les médias déjà indexés. Ils ne sont pas exécutés par cron.

L’analyse est en lecture seule. Une sauvegarde SQLite est créée automatiquement avant toute correction. Les futures migrations de classement sont versionnées et exécutées une seule fois.
Action après modification des règles de sources

Recalcule la catégorie de toute la médiathèque selon les forces et indices d’URL actuels. Cette action peut déplacer beaucoup de médias et reste volontairement manuelle.
