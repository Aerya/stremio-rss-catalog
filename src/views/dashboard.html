Maintenance

Actions ponctuelles sur la base de données.

Reclassifier les animés

Parcourt tous les films & séries déjà indexés et détecte ceux qui sont des animés (genre Animation TMDB + langue japonaise). Met à jour leur catégorie en base. Nécessite une clé TMDB.

Reclassifier les documentaires

Parcourt tous les médias déjà indexés et détecte ceux qui sont des documentaires (genre 99 TMDB déjà stocké en base). Aucun appel API nécessaire.

Corriger les faux documentaires

Détecte les médias classés en documentaires qui ont des genres incompatibles (Action, Science-Fiction, Fantastique, Horreur) et les remet en Films ou Séries. Aucun appel API nécessaire.

Corriger les fausses émissions TV

Détecte les séries classées en émissions qui ont des genres incompatibles (Science-Fiction, Fantastique, Animation, Horreur) et les remet en Séries. Aucun appel API nécessaire.

Reclassifier par configuration de flux

Reclassifie tous les médias selon la configuration actuelle des flux (force manuel + détection automatique depuis l'URL du flux). Aucun appel API nécessaire.

Reclassifier les concerts

Détecte les médias avec le genre Music TMDB (10402) sans genres narratifs contradictoires et les reclassifie en concerts. Aucun appel API nécessaire.

Corriger les faux concerts

Détecte les médias classés en concerts avec des genres narratifs contradictoires (Drama, Action, Horreur…) et les remet en Films ou Séries. Aucun appel API nécessaire.

Reclassifier les spectacles

Détecte les médias dont le nom de release contient des mots-clés de spectacle (Stand-up, One Man Show, Théâtre, Cirque…) et les reclassifie. Aucun appel API nécessaire.
